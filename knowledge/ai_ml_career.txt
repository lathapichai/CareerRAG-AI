EMBEDDINGS

Embeddings convert text into numerical vectors.

Texts with similar meanings can have similar vector representations.

Embeddings are useful for:

Semantic search
Recommendation systems
Document retrieval
RAG applications
Similarity matching


SENTENCE TRANSFORMERS

Sentence Transformers are models used to convert sentences and paragraphs into numerical embeddings.

CareerPilot AI uses the all-MiniLM-L6-v2 Sentence Transformer model.

The model converts text into vectors that represent the meaning of the text.

Example:

"What is machine learning?"

and

"Explain machine learning to me."

These sentences use different words but have similar meanings.

Their embeddings can therefore be close to each other.


FAISS

FAISS is a library for efficient similarity search of vectors.

FAISS can store embeddings and search for the most similar vectors.

CareerPilot AI uses FAISS as the vector search component of the RAG system.


RAG

RAG stands for Retrieval-Augmented Generation.

A RAG system retrieves relevant information from a knowledge base before sending the information to an LLM.

Basic RAG workflow:

User Question
↓
Convert question into embedding
↓
Search vector database
↓
Retrieve relevant documents
↓
Send retrieved information to LLM
↓
Generate answer

RAG can provide an LLM with relevant information from an external knowledge source.

Important RAG components include:

Documents
Text chunks
Embeddings
Vector database
Similarity search
Retrieved context
Language model
